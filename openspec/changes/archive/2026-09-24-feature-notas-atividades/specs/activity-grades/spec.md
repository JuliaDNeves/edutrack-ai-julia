# activity-grades Specification

## Purpose

Defines the specification for allowing teachers to launch grades for student activities in EduTrack AI.

## ADDED Requirements

### Requirement: Launch activity grade
The system SHALL allow launching a grade for a specific student activity.

#### Scenario: Teacher submits a grade for an activity
- **WHEN** teacher submits a grade for a student activity
- **THEN** system stores the activity grade associated with the student activity and user_id
